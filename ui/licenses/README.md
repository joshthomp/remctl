# License source

`cfworker-LICENSE.txt` is the license for `@cfworker/json-schema` 4.1.1, whose npm archive omits it. Retrieved from its published gitHead:

https://github.com/cfworker/cfworker/blob/5409fdc2bd144f68e8b28c61c71fcb16600000a6/LICENSE.md

Other dependency notices are read directly from the installed, locked npm packages by `python3 scripts/build_ui_notices.py`. Regenerate `ui/THIRD-PARTY-NOTICES.txt` after updating UI dependencies. Source-build users consume the checked-in notices and need no npm installation.
